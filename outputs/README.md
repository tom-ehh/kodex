JSON configurations for the six forms to digitise (organisers' `new_downloads/` 2, 3, 4, 6, 7, 8), generated by the Kodex pipeline (`POST /api/v1/forms/analyze`, `main` at 924f2ba) on 2026-11-22 and then lightly corrected by hand.

| Path | What |
|---|---|
| `<slug>.json` | **Submitted output**: pipeline output + the light corrections below |
| `raw/<slug>.json` | Untouched pipeline output (the `form` from the envelope) |
| `corrections.py` | The script that applies the corrections (raw -> submitted) |
| `screens/` | Every tab of each submitted file in the Form Preview (`/preview`), plus `gate-*.png` checks of the conditional fields |

All six submitted files: 0 issues from `kodex.schema.form.validate_form_definition`, "Brak problemów" in the preview, every tab renders, no console errors.

## Corrections

Kept light: removing duplicates and paper-only artefacts (signatures, office-only boxes), fixing requiredness and broken show/hide rules. No content was invented beyond the pełnomocnik toggle, which the paper implies ("if a pełnomocnik acts").

### zwrot-oplaty-skarbowej
- added checkbox 'Wniosek składa pełnomocnik'; pełnomocnik data/attachments shown only when ticked (paper: fill in only if a pełnomocnik acts)
- Nr rachunku and Dane właściciela REQUIRED when shown (bank transfer chosen); pełnomocnictwo files REQUIRED when shown
- removed 'Data i podpis' section (the e-service signs electronically and dates the submission)

### wydanie-zaswiadczenia
- removed 'Podpis wnioskodawcy' section (electronic signature)
- office address fields no longer REQUIRED (prefilled by the office, not the citizen's input)

### wynajecie-swietlicy-wiejskiej
- removed applicant fields duplicated in 'Podpis i dane kontaktowe' and both 'Czytelny podpis' uploaders; section renamed 'Dane kontaktowe'

### zajecie-pasa-drogowego
- removed section 'Zakres i sposób wykonania robót' (duplicate of the 'Rodzaj robót i sposób wykonania' textarea)
- repeating 'Powierzchnia zajęcia' section: dropped the '… 2' copies of each row (repeat the section instead)
- typo: 'Opłaty skarbne' -> 'Opłata skarbowa'
- added checkbox 'Wniosek składa pełnomocnik'; pełnomocnik data/attachments shown only when ticked (paper: fill in only if a pełnomocnik acts)

### psy-ras-agresywnych
- removed office-only fields (Nr sprawy, pieczęć, data, wydział: 'wypełnia organ')
- 'Przedmiot wniosku' section: removed the dog/address/conditions fields duplicated by the repeating 'Informacja o posiadanym psie' and the two sections after it
- repeating dog section: dropped wrong SHOW states (breed, birth date etc. were hidden until a marking was chosen); added 'Numer identyfikacyjny' per dog, shown and REQUIRED for mikroprocesor/tatuaż

### oplata-za-odpady
- removed spouse fields inlined in 'Dane podmiotu' (same fields already in the 'Dane współmałżonka' section, same SHOW rule)
- removed the two signature uploaders (electronic signature); section renamed 'Składający deklarację'

## Known gaps left as generated

- Computed values (fee sums, areas, number of days) are plain inputs, not calculated.
- Consents and statements are Tak/Nie radios, not single required checkboxes.
- Phone numbers have no validator.
- Pipeline bug seen in psy: two SHOW states on one field mean AND in the preview, so "mikroprocesor OR tatuaż" never showed. Fixed here by hand as one `or` query; the generator still needs a fix.
